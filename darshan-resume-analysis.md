**WHY IT MATTERS:** The headline implies employable GenAI engineering experience.

**EXACT FIX:** Use `Cloud & DevOps Engineer | AWS, EKS, Kubernetes, Terraform and Observability`. Keep GenAI as a project area.

### 2. Target role clarity

**PROBLEM:** DevOps and cloud positioning is strong, but GenAI creates a second, less-supported target.

**WHY IT MATTERS:** It dilutes an otherwise credible infrastructure profile.

**EXACT FIX:** Lead with Cloud/DevOps. Create a separate AI-enabled DevOps version only after the RAG project has stronger implementation detail.

### 3. Professional summary

**PROBLEM:** The summary is keyword-heavy and includes broad claims such as designing scalable, highly available architectures.

**WHY IT MATTERS:** Strong claims need supporting examples and scope.

**EXACT FIX:** Reduce the tool list and lead with the Fujitsu production scope, EKS/Terraform responsibilities and one measurable operational result.

### 4. Technical skills

**WHY IT MATTERS:** Recruiters scanning skills may miss relevant strengths.

### 5. DevOps experience
